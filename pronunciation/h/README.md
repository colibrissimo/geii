# The letter H

**Status: built 18 Aug 2026. Audio verified. Not yet on Moodle.**

Self-contained static deck, same shell as `short-long-i`. No account, no
subscription, works offline from a USB stick. Open `index.html`.

## Counts
- **12 slides** (title, index, 8 content, quiz, thanks)
- **48 recordings**, all 48 used, none missing
- **10 minimal pairs**
- **18 words sound their H · 30 do not** — the quiz pool is all 48, ten per round
- **0 images, 0 videos** — this deck is typographic; see "What is missing" below

## Navigation
Same as `short-long-i`: arrow keys / space / on-screen ‹ ›, `Home` or ⌂ returns
to the index, `#7` in the URL opens directly on slide 7.
Moodle link straight to the quiz: `.../h/#11`

## The three problems, in order
1. **Saying it** — /h/ does not exist in French, so the gesture is unused rather
   than difficult. 18 words.
2. **Not saying it** — H written and silent. 13 words: *honest, honour, hour,
   ghost, exhaust, exhibit, vehicle, rheostat, shepherd, what, when, where, why*.
3. **Not inventing it** — the over-correction, h-energy / h-apple / h-idea.
   7 words beginning on a bare vowel.

## The ten pairs
air·hair · and·hand · arm·harm · art·heart · ate·hate · ear·hear · eat·heat ·
eye·high · ill·hill · old·hold

## Decisions taken 18 Aug 2026
- **`who` and `whose` are filed as sounding their H**, against the other wh-
  words. This is the trap in the set and it is called out in prose on the
  silent-H slide rather than left for students to trip over in the quiz.
- **Quiz key, verified word by word:** *exhaust* /ɪɡˈzɔːst/, *exhibit*
  /ɪɡˈzɪbɪt/, *vehicle* /ˈviːəkl/, *shepherd* /ˈʃepəd/, *rheostat* /ˈriːəstæt/,
  *ghost* /ɡəʊst/ — all no /h/. *perhaps* /pəˈhæps/ and *behind* /bɪˈhaɪnd/ —
  /h/ present, though not word-initial. The quiz asks "did you hear an /h/",
  not "at the start", for exactly those two.
- **Silent-H words are printed with the h struck through** on slide 7, so the
  eye and the ear get the same information.
- **No `assets/img`, no video.** Nothing was available. The title uses a
  breathing CSS H; sections use oversize letterforms and the shared dot fields.

## Audio provenance
